# 紫微兄友线专题方法论（飞星派四化 · 按需 Read）

> 本文件为紫微斗数**飞星派「兄友线」专题**方法论文档。理论来源：飞星派口传体系（2026-10 用户提供）+ 同期本命主实战验证。**按需加载**：用户要求深断**人际 / 朋友 / 合伙 / 兄弟 / 现金流 / 众生缘**议题，或指定"兄友线 / 交友宫 / 兄弟宫 / 自化 / 飞宫 / 绝情位"分析时 Read 本文件。调用时遵循 SKILL.md 核心铁律（严谨、附依据、置信度标注、正向引导、免责声明）。
>
> **代号约定**（飞星派通例）：**A=禄、B=权、C=科、D=忌**；小写 a/b/c/d 指自化（离心=飞出宫外丢失，向心=他宫飞入，另注明）。三个基础概念：
> - **生年四化**：出生年干四化（先天格局，"命里带的"）；
> - **自化**：某宫**宫干**四化落回**本宫**主星（该宫能量的自我消耗 / 漏损）；
> - **飞化**：某宫宫干四化落**他宫**（两宫之间的能量输送管道）。
>
> 标注体系：理论断语标 `[飞星派]`（派别技法，未经古籍交叉），实战印证标 `[项目验证]`。

## 一、兄友线的地位（本派纲目）`[飞星派]`

- **兄友线（兄弟宫—交友宫）+ 父疾线（父母宫—疾厄宫）为人生重大两条线**，而非外面所讲的"重在命财官迁"。兄友线是**众生缘线**（朋友、合伙人、人际、六亲气数），父疾线是**禀赋线**（文书、贵人、身体）。
- 兄友线不只是"看人际"——两宫各自身兼数职（见下节），是全盘信息密度最高的轴线之一。

## 二、兄友两宫的多重含义 `[飞星派]`

| 宫位 | 含义一 | 含义二 | 含义三 |
|---|---|---|---|
| **交友宫（仆役）** | **配偶身体位** | 六亲健康位 | 人际人脉位 |
| **兄弟宫** | **现金流位** | 身体气数位（疾之九）| 阴阳宅风水（田之三合）|

断兄友线时按议题取对应含义：问合伙朋友看人脉位、问配偶健康看交友之疾象、问财务周转看兄弟现金流。

## 三、生年四化落兄友线（单象论）`[飞星派]`

**总纲**：兄友线见**生年四化（无论禄权科忌）主朋友有助益**，只是力量大小、强弱、多少不一。

| 生年四化 | 通义 |
|---|---|
| **生年禄** | 朋友送好处（财源、机会、情谊），得朋友之力 |
| **生年权** | 朋友有权势助力 / 强势朋友（见复合象节） |
| **生年科** | 朋友是贵人、以文会友、清谈之交 |
| **生年忌** | **"朋友有的劫"——没事**（忌是朋友自己带来的功课，不是你必须被劫；与自化忌天壤之别，见第五节）|

## 四、自化论（兄友线宫干四化落回本宫）`[飞星派]`

| 自化 | 通义 |
|---|---|
| **自化禄（a）** | 朋友圆融，但**朋友易劫财**：借出去的钱不一定收得回；朋友一起吃喝多半自己掏钱；**损财后心甘情愿**（禄=甘愿）|
| **自化权（b）** | 朋友想从你这得到资源且**要求高**，给的不到位会有争执——**这种命格须做授权高手才行**。共事上是好事，但隐含破耗（"努力中的消耗"，见第七节转宫查耗）|
| **自化科（c）** | 朋友间风花雪月、圆融能聊，**不一定有经济往来** |
| **自化忌（d）** | **欠朋友债**：欠别人的钱会还，别人欠自己的不一定还；**破得不心甘情愿**。⚠ 全线最凶单象（见第五节）|

**组合断法**：

- **兄友线 BCD 俱见**：朋友**三教九流**——比自己高的（上亿）、比自己低的（几千）都有，人脉横跨阶层。
- **兄友线只见 A（禄）**：**广缘**——随缘际遇、一团和气、转眼即忘，非知心朋友而是流于表面；**做生意可以**（卖东西给别人未必熟，热心即可）。
- **复合象**（生年四化 × 自化叠参，"A 自化 ABCD"全组合思维）：例——**生年权 + 自化忌 = 从朋友得到好处又被劫财**：朋友介绍一笔大业务（权之助力），你给佣金是做人本分，但自化忌使你**表现得不甘心、给得少**，故起争执。断法：先看生年四化定"得到什么"，再看自化定"怎么漏、甘不甘愿"。

## 五、自化忌 vs 生年忌（本派最重要分野）`[飞星派]`

> **兄友线自化忌最不好，无论离心、向心都不好；生年忌没事——生年忌反而是"朋友有的劫"，自化忌则"你必须被劫"，这没有办法的事。**

- **生年忌**在兄友线：劫是**朋友的**（朋友自己带课题来），我方损失有限、可控；
- **自化忌**在兄友线：**"你必须被劫"**——欠众生缘的债，跑不掉；
- 但"这里不好就看你怎么操作了，**你得完成这个任务**"——自化忌是功课清单，不是死刑：**完成了，这条线的正财才归你用**。
- 心法（正向）：**劫出去的财会减轻配偶身体位的压力**——可理解为多普渡众生（欠众生缘的债，你来还），反过来对自己好——**你只是帮助自己**；那个符号变化是你命中的，不是别人命中的，此乃运命法则。

## 六、飞宫论（宫干飞化 + 绝情位）`[飞星派]`

### 6.1 兄友两宫宫干飞化四路

取兄弟宫、交友宫的**宫干**四化，看飞落何宫（重点落宫：入命=送我、入官禄=助事业、入兄友=互劫、入**大限命宫**=课题在该十年激活）：

| 飞化落宫 | 通义 |
|---|---|
| 友禄/友科 **入命宫** | 朋友送助力、送贵名上门（机会、推荐、业务主动来）|
| 友权 入官禄 | 朋友在事业上推一把 |
| 友忌 入某宫 | 朋友线的消耗 / 课题落在该宫（转宫解读，见 6.2）|
| 兄忌（宫干忌）入文书/银行位（父母） | 现金流问题牵动合同、债务、贷款 |

### 6.2 转宫查耗

自化权（b）等隐含的**破耗**，转一下落宫就知道耗在哪：如自化 b 转进田宅（太阴），= 为生意交际影响身体 / 为店面公司而耗。**权忌都有耗**（运动员的权更是耗）——破耗 = **努力中的消耗**，不必闻"耗"色变。

### 6.3 绝情位

**任何宫位之交友宫，谓之该宫的"绝情位"；绝情位不宜冲入本宫**：

- 例：子女宫的交友宫 = 福德宫 → **福德不宜冲子女**（大限同论）；
- 同理：**任何宫不宜忌入兄友线**（兄友=众生缘线），**冲友比冲兄更甚**；
- 应事：**财忌入注意损财、子忌入注意怀孕、疾忌入注意身体**——也许是欠众生债，但此理**并非无解**。

### 6.4 飞宫假设的克制（铁律）⚠

> **飞宫假设切忌要理解：不是平衡学问。**

飞化断吉凶必须**结合命主身份**：如"大官忌冲疾"——**只有当老板的断倒闭，打工的另当别论**。故不可胡乱套入解释。凡按本文件断飞化，先问命主在该领域的**身份角色**（老板 / 打工 / 合伙），再定断语量级；身份不符，断法打折或不下。

## 七、权的心法（命官之权 × 兄友之禄）`[飞星派]`

- **命宫 / 官禄有权，而兄友线无禄**：没人陪你玩，只是自己得瑟——杠精、看谁都不顺眼、主观霸道（权自己占了）。碰到此类权，只管让他赢，他便会迷失在自我里。
- **权的正面**：权威技术、领导风范、有说服力、会带领、气场强悍、有追随者（山呼万岁）。
- **权禄分居（官禄有权 + 兄友有禄）= 权有人配**：自己有本事，外面有人捧场——权不孤立的良构 `[项目验证]`。断法：见命官之权，必回头查兄友线有无禄（生年禄 / 友禄入命）配位，权才落得了地。

## 八、断法流程（Checklist，下次照此走）

1. **定两宫**：兄弟宫、交友宫的宫支、宫干、星曜（主星 + 煞星，地劫 / 擎羊等劫耗星重点标）；
2. **查生年四化**：有无落兄友线（禄权科忌单义，见第三节）；
3. **查自化**：两宫宫干四化是否落回本宫（A/B/C/D 单象 + 与生年四化的复合象，见第四节）；
4. **宫干飞化四路**：两宫宫干四化各落何宫（重点：入命、入官禄、忌落宫、是否落大限命宫）；
5. **叠大限**：兄友线四化 / 飞忌是否激活当前大限（忌入大限命宫 = 该十年课题集中）；
6. **身份打折**：按 6.4 结合命主身份（老板 / 打工 / 合伙）定断语量级；
7. **操作建议**（正向收口）：只合作不借贷 / 佣金规则先行 / 朋友圈分层用（贵人级请教、开创型立规则）/ 被劫以"还众生债"心法转念——每个凶象配一条出路（SKILL 铁律 8）。

## 九、实战案例 `[项目验证]`（某男命 · 癸年生 · 2026-10）

> 案例脱敏：保留四柱结构 / 事件类型 / 引动机制 / 年份，隐去个人敏感信息。

**盘面**：兄弟宫@戌（壬干）破军[旺]·**禄** + **地劫**；交友宫@辰（丙干）紫微[得] + 天相[得] 无煞。生年四化（癸）：破军禄→兄弟宫、巨门权→官禄、太阴科→福德、贪狼忌→田宅。

**逐层断与验证**：

| 断 | 结构 | 应事验证 |
|---|---|---|
| 生年禄坐兄弟宫 = 朋友有助益（破军 = 开创型大进大出之助）| 理论第三节总纲 | ✅ 人脉介绍的技术外快（2025 乙酉年应）|
| **禄劫同宫** = 送机会与劫财同一批人 | 破军禄 + 地劫同坐 | ✅ 合伙破财重负但**扛住未跑路**（己未大运实况）——**禄托住劫**：有禄之劫伤而不死 |
| 无自化忌 ≠ "必被劫" | 壬 / 丙四化均不落回本宫 | ✅ 被劫是"禄劫同宫"的**模式性消耗**（可操作改变），非宿命性劫 |
| 友丙干飞**禄 + 科双入命宫**（天同禄 / 文昌科）| 友禄友科入命 | ✅ 机会与推荐主动上门（技术外快由人脉递到手上）|
| 友丙干**廉贞忌入子女宫** = 恰为 32–41 大限命宫 | 忌入大限命 | ✅ 该十年（约 2024–2033）人际 / 合伙钱财课题集中（合伙重负实况落在限内）|
| 兄壬干**武曲忌入父母**（文书 / 银行位）| 现金流位忌入文书位 | 🟡 现金流问题牵动合同 / 债务（与实况方向合，置信中）|
| 权禄分居（官禄巨门权 + 兄弟破军禄）= 权有人配 | 第七节 | ✅ 专业权威有人捧场，非"自己得瑟"之局 |
| 交友紫微天相 = 朋友三教九流、层次横跨 | 第四节组合断 | ✅ 贵人级（紫相）与开创型（破军）两类并存 |

**操作建议落地**（该命主）：① 只合作不借贷，佣金权责先写纸上（禄劫同宫的劫从"情分代替规则"处开口）；② 权留在专业上（官禄权），不带进合伙谈判压人；③ 现金流大进大出有活水也有漏口——进项靠开新，堵漏靠不担保不垫资；④ 忌入限十年以"还众生债"心法行普渡，完成后禄归己用。

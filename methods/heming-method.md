## 第一部分：紫微合盘

### 一、双宫联参核心

批婚姻/感情，**必须夫妻宫 + 福德宫同看** `[命理共识]`：
- **夫妻宫**：看配偶的星性、外形、性格、互动模式
- **福德宫**：看深层感情、婚姻能否长久

单看夫妻宫易误判——夫妻宫好而福德宫破，感情仍难久。

### 二、合盘五步法

1. **双方命格基础**：双方命宫 + 身宫 + 福德星性是否般配（同类或互补型）；警戒双方皆杀破狼格（两虎相争）或一强一弱过度悬殊
2. **夫妻宫互参**：甲方夫妻宫主星是否对应乙方命宫/三合方星；双方夫妻宫各自的四化状态（化禄/化忌影响最大）
3. **太阳太阴星象**：女命太阳代表丈夫（庙旺=旺夫，落陷化忌=克夫之象）；男命太阴代表妻子（庙旺=妻美贤，化忌=婆媳不和之象）
4. **本命四化互参**：甲方生年四化星落乙方哪宫（化禄入对方命/财=正向帮助；化忌入对方夫妻=带给对方婚姻伤害）
5. **大限同步**：双方当前大限是否同走旺运（俱旺=最佳时机，俱衰=共同挑战）

### 三、缘分类型

| 四化引动 | 缘分特征 |
|---|---|
| 化禄引动 | 正缘、真爱，感情甜蜜顺遂 |
| 化权引动 | 主动争取型，有张力、有主导方 |
| 化科引动 | 和谐相处、互相尊重，白头偕老型 |
| 化忌引动 | 逆缘/冤家，彼此折磨但难分离，需修行化解 |
| 双方互化忌 | "冤家路窄"型，感情强烈但痛苦并存 |

### 四、婚期三层法

1. **本命盘**：夫妻宫无煞宜早婚；有煞无吉或武曲/廉贞/七杀/破军在夫妻宫宜晚婚（男30以上，女27以上）
2. **大限**：大限夫妻宫吉星多→该十年有结婚机会；化忌→感情受阻
3. **流年**：红鸾、天喜入命宫或夫妻宫→该年婚恋有动；流年宫落夫妻宫→婚姻是重点

### 五、克夫/克妻标志（概率性提示，非定论）

以下配置出现时**提示需注意**（非必然）：夫妻宫廉贞+贪狼/破军/七杀组合、太阳落陷化忌（女命）、太阴化忌（男命）、夫妻宫四煞齐聚无吉星、孤辰寡宿入命或夫妻。

> [倪海厦视角]天纪有"克非感情不好，而是感情太好所致"之说——克是情深之象，非单纯负面。

### 六、事业合作合盘

主看官禄宫 + 兄弟宫（合伙位）+ 仆役宫（朋友下属位）+ 福德宫（能否同甘共苦）联参 `[命理共识]`。吉象：双方命宫互补（一谋一行）、一方官禄化禄入另一方官禄。凶象：双方化忌互冲官禄、巨门在兄弟/仆役（易合伙生是非）。兄弟线深断（含现金流/众生缘）见 `methods/ziwei-xiongyou.md`。

## 第二部分：八字合婚

> 独立体系，不含紫微术语（宫位/星曜/四化/大限）。

### 一、神煞相配

看双方命局神煞是否互补或相冲 `[古诀]`。如一方桃花星（咸池/红艳）旺而另一方孤辰寡宿，需注意感情节奏差异；双方皆带华盖则性情相投但偏孤。

### 二、年柱纳音

双方年柱纳音五行生克 `[古诀]`：纳音相生（如一方金、另一方水，金生水）为顺；相克需看有无通关。纳音仅作参考，不为主。

### 三、五行互补

看双方日主五行及命局五行旺衰是否互补 `[命理共识]`：一方命局所缺/所弱，恰为另一方所旺/所多，则互补互益（如一方火弱、另一方火旺）。双方五行严重同偏（如都金水极寒）则调候互难。

### 四、日主十神关系

看双方日主的生克关系 `[命理共识]`：双方日主相生相助（如甲木与乙木、甲木与丙火）为顺；相克（如甲木与庚金）为逆，需看双方命局能否化解。再参双方命局十神：一方官杀旺配另一方印旺（官印相生互补）、一方财旺配另一方比劫旺（能担财），均为互补良配。

### 五、古籍源流与日柱夫妻星宫法

**合婚五法源流**（由粗到细）`[古诀]`：

**日柱夫妻星宫法** `[古诀]`——"男以财为妻，女以官为夫"，合婚看四件事：

1. **星之喜忌**：男命财为用→娶妻得助，女命官为用→嫁夫有靠（星为忌则因婚致累）；
2. **星之旺衰**：有根则缘实，虚透则缘浮；
3. **夫妻宫（日支）**：刑冲破害则家宅多磨，安静相合则稳；
4. **对方是不是我的星**：对方日主恰为我之妻星/夫星（如甲日主遇辛日主=互为正财/正官）为"星入对方之身"的强配——此为静态合婚的最强结构之一。

## 第三部分：合盘应期法（共时应期）`[项目验证]`

> 关系事件（相见、定情、争执、成婚、分离）多为**两人盘同时被引动的共时产物**——单看一方盘的应期常错位。本部分为项目自创技法（核心骨架为古籍合冲体系 `[古诀]`，"共时应期"框架为本技法人所创 `[项目验证]`，引用时不冒充古诀）。

### 一、定义与原理

**同一流年 / 流月 / 流日地支，同时合动（合 / 冲 / 刑 / 害 / 伏吟）双方命局中"对应同一议题的宫位"→ 该议题事件在此时共时发生。** 双方引动 > 单方引动：共时应事的概率与烈度显著更高。

### 二、判定规则

1. **找双方对应议题宫位**：婚姻 / 亲密 → 双方**日支**（夫妻宫）；性事 / 隐私 → **时支**；同居 / 家宅 → 日支+时支（八字）或田宅宫（紫微）；六亲议题 → 对应六亲宫位。
2. **查当前流层（年 / 月 / 日）地支**对双方对应宫位的作用类型（合 / 冲 / 刑 / 破 / 害 / 伏吟）。
3. **作用类型定事件性质**：**合 = 成 / 聚 / 交好；冲 = 开 / 动 / 裂；刑 = 激烈搅动 / 磨合；伏吟 = 事发动 / 反复；害 = 暗损 / 小别扭**。
4. 共时（同一支动双方）＞ 单方：共时为"事件级"，单方为"心绪级"。

### 三、已验证案例（两例，脱敏）

| 案例 | 流层 | 引动 | 应事 |
|---|---|---|---|
| 1（年级） | 流年午 | **午戌半三合（火局拱合）动男方妻宫 + 午未六合女方夫宫**——一支双合两人婚姻宫 | 当年婚恋之事成为两人共同主题，全年多次应事（会面、关系推进）✅ |
| 2（日级） | 流日卯（己卯日） | **卯戌合×2 男方（月 / 日支）+ 卯未合×2 女方（年 / 日支）**——一支双合两人婚姻宫；同时**卯冲女方时支酉（时柱主隐秘位）** | 相见定情日；且"合主宫 + 冲辅宫"对应"关系实质推进而事有未竟"（合=成、冲=开而未成的行为级对应）✅ |
| 3（日级三连） | 己亥月 戊子日→己丑日→庚寅日 | **子日：害女夫宫×2 + 破女时支（隐秘宫）双"不成"信号；丑日：冲女夫宫×2；寅日：合男妻宫×2 + 男日主临官禄 + 火长生（女夫星得生）+ 杀透（决断）** | 同一亲密事件的三日三步：**爱而未合（害+破）→ 分居两地（冲）→ 事成（合）**——取象语言表（害破=未成/冲=分开/合=成）迄今最完整的连续验证 ✅（纪律：复盘解释，非预测）|

### 四、纪律（铁律）

1. **溯源标注**：合冲骨架 `[古诀]`，共时框架 `[项目验证]`，不混标；
2. **精度边界**：行为细节级断语（如亲密程度）属**取象延伸**——案例 2 仅一例验证，**只可作复盘解释，🔴 禁作事前预测**（"某日会发生 X 行为"类断语禁下）；
3. **用途限定**：用于已发生事件的复盘验证 + 月份级窗口提示（"某月成色高"级），不做日级行为预测；
4. **两体系独立**：八字体系用地支合冲 + 四柱宫位表述；紫微体系用流年走宫 + 四化落宫表述——各自使用不混术语；
5. **原局全矩阵纪律** 🔴：合盘时必须跑**双方全部干支的两两交叉关系矩阵**（引擎 `bazi_relations` 的 analyzeZhiRelations/analyzeGanRelations 交叉调用），**禁挑看**——首例审计曾漏看 3 组酉戌害与 1 组酉酉自刑（含"她夫星座酉 ↔ 他妻宫戌相害"这类关键静态结构）。原局静态矩阵给出"磨合面全图"，流层双合给出"应期驱动"——两者分开表述。

## 第五部分：婚姻全维度推演法（婚后动态推演）`[项目验证·2026-11]`

> 合婚不止看"当下般配"（静态四法/共时应期），更要推**婚后生活**（动态）：能量交互 → 大运纠缠 → 五维科目 → 流年预警。2026-11 首例推演并引擎核验后沉淀。

### 一、能量交互（原局动态咬合）

- **双通道对流**：查两人五行互送——A 的旺神是否为 B 的用神、B 的旺神是否生 A 的日主/印星。双向流（"她养他的印/他洗她的金"式）优于单向输送；
- **交叉纠缠**：A 的大运五行是否旺 B 的星（如 B 走水运恰旺 A 的印、A 走火运恰是 B 的夫星——**运互相成全**为上等婚的动态标志）；
- **堵点定位**：两人相克的两套系统落在哪（如**双方印星相克 = 两套庇护系统互耗 → 婆媳/两家课题**）——堵点即婚后主功课所在。

### 一之二、五行药理分析法（对方的盘是不是我的药）`[项目验证·2026-11]`

> 互补只看"缺/旺"，药理看"病与药的机制"——对方入局后，我的死结是否被解开、断链是否被焊通、旺神无制是否被制。这是"能量交互"的精细层。

**五步法**：

1. **找病**：各自盘的病灶——①两行相战无通关（如财坏印）；②五行断链（旺神无泄口，如金旺无水、气憋不发）；③旺神无制攻身（如杀透无食伤制）；
2. **找药**：对方的旺神/透干之神是否对症——
   | 我的病 | 对方当补的药 | 经典范式 |
   |---|---|---|
   | 财坏印（土克水） | **金通关**（财生官→官生印→印生身，敌对变连环生）| 通关之神 |
   | 土厚埋金 | **木疏土 + 水润土**（疏板结、润燥土，死土变生金之母）| 松根活土 |
   | 辛金蒙尘无洗 | **壬水淘金**——`[古诀]`**金白水清**（珠玉得清水洗，出土发光）| 淘洗之神 |
   | 杀攻无制 | 制杀之神（食伤制杀/对方旺神直克其杀）| 安心之神 |
   | 旺神断链 | 对方旺神作**泄口续链**（我之金→彼之水→我之财，才华经对方变现）| 流通之神 |
3. **验药力**：药神有力否——透干有根为健康之药；**受刑冲破害者为残药**（关键鉴别：我自家盘里可能本有此神但被伤——如官星坐酉被戌害=自家通关之神残缺，对方补入的须是**透干无伤**的健药方为真解）；
4. **对称判读**：互为解药（A 是 B 的药且 B 是 A 的药——上等婚的五行标志）/ 单向入药（一方是药一方是病——失衡结构）/ 互为病（相耗）——**并各给一字定性**（如"她给转化（通关），他给出口（流通）"）；
5. **诚实边界**：列出**对方也补不了的科**（双方同缺之维，如双方子女星俱弱）——此维无人是药，只能共同面对（医学/时间窗），不得粉饰。

**首例存照（脱敏）**`[项目验证]`：男方财坏印（土旺克水）+自家官星被酉戌害伤（残药）——女方双辛透干+酉禄（健药）入局成**金通关**：财生官→官生印→印生身；女方土厚埋金+全局无水+杀攻无制三病——男方壬水透干（淘金：金白水清）+甲木日主（疏土松根）+水克丁火（制杀安心）三药齐下，并焊通女方"土→金→水绝"断链（男方水为其金之泄口，续至其财）。对称判读：**她修他的命（转化），他续她的脉（流通）——互为解药**。边界：双方子女星俱弱，此科同缺无药，医学面对。

### 二、大运对位（区间精确化·铁律）

1. **对位区间 = 两人大运的公历交集**——两人起运岁不同，**禁止粗略"十年对十年"**：先换算（公历年 = 出生年 + 虚岁 − 1），再取双方同运的重叠段（如男丙辰 2047–2056 × 女甲辰 2045–2054 → 交集 2047–2054）；
2. **三型判读**：① 各自用神运 + 交叉互旺 = **黄金段**；② 一顺一险 = **接力互补段**（强方扛弱方，看弱方险在哪：健康/财/名）；③ **双方同冲婚姻宫之运**（如双辰同冲双戌）= **大考段**——提前预知、刻意经营、忌分居；
3. 🔴 **核验纪律**：对位区间与年龄**必须排盘核验**（首例曾错标年龄与粗区段，实测纠正——凡年份/虚岁/交集，一律引擎复核，禁心算入库）。

### 三、婚后五维科目（十神即婚姻现实）

## 第一部分：紫微合盘

### 一、双宫联参核心

批婚姻/感情，**必须夫妻宫 + 福德宫同看** `[命理共识]`：
- **夫妻宫**：看配偶的星性、外形、性格、互动模式
- **福德宫**：看深层感情、婚姻能否长久

单看夫妻宫易误判——夫妻宫好而福德宫破，感情仍难久。

### 二、合盘五步法

1. **双方命格基础**：双方命宫 + 身宫 + 福德星性是否般配（同类或互补型）；警戒双方皆杀破狼格（两虎相争）或一强一弱过度悬殊
2. **夫妻宫互参**：甲方夫妻宫主星是否对应乙方命宫/三合方星；双方夫妻宫各自的四化状态（化禄/化忌影响最大）
3. **太阳太阴星象**：女命太阳代表丈夫（庙旺=旺夫，落陷化忌=克夫之象）；男命太阴代表妻子（庙旺=妻美贤，化忌=婆媳不和之象）
4. **本命四化互参**：甲方生年四化星落乙方哪宫（化禄入对方命/财=正向帮助；化忌入对方夫妻=带给对方婚姻伤害）
5. **大限同步**：双方当前大限是否同走旺运（俱旺=最佳时机，俱衰=共同挑战）

### 三、缘分类型

| 四化引动 | 缘分特征 |
|---|---|
| 化禄引动 | 正缘、真爱，感情甜蜜顺遂 |
| 化权引动 | 主动争取型，有张力、有主导方 |
| 化科引动 | 和谐相处、互相尊重，白头偕老型 |
| 化忌引动 | 逆缘/冤家，彼此折磨但难分离，需修行化解 |
| 双方互化忌 | "冤家路窄"型，感情强烈但痛苦并存 |

### 四、婚期三层法

1. **本命盘**：夫妻宫无煞宜早婚；有煞无吉或武曲/廉贞/七杀/破军在夫妻宫宜晚婚（男30以上，女27以上）
2. **大限**：大限夫妻宫吉星多→该十年有结婚机会；化忌→感情受阻
3. **流年**：红鸾、天喜入命宫或夫妻宫→该年婚恋有动；流年宫落夫妻宫→婚姻是重点

### 五、克夫/克妻标志（概率性提示，非定论）

以下配置出现时**提示需注意**（非必然）：夫妻宫廉贞+贪狼/破军/七杀组合、太阳落陷化忌（女命）、太阴化忌（男命）、夫妻宫四煞齐聚无吉星、孤辰寡宿入命或夫妻。

> [倪海厦视角]天纪有"克非感情不好，而是感情太好所致"之说——克是情深之象，非单纯负面。

### 六、事业合作合盘

主看官禄宫 + 兄弟宫（仆役，代表合伙）+ 福德宫（能否同甘共苦）联参 `[命理共识]`。吉象：双方命宫互补（一谋一行）、一方官禄化禄入另一方官禄。凶象：双方化忌互冲官禄、巨门在兄弟/仆役（易合伙生是非）。

## 第二部分：八字合婚

> 独立体系，不含紫微术语（宫位/星曜/四化/大限）。

### 一、神煞相配

看双方命局神煞是否互补或相冲 `[古诀]`。如一方桃花星（咸池/红艳）旺而另一方孤辰寡宿，需注意感情节奏差异；双方皆带华盖则性情相投但偏孤。

### 二、年柱纳音

双方年柱纳音五行生克 `[古诀]`：纳音相生（如一方金、另一方水，金生水）为顺；相克需看有无通关。纳音仅作参考，不为主。

### 三、五行互补

看双方日主五行及命局五行旺衰是否互补 `[命理共识]`：一方命局所缺/所弱，恰为另一方所旺/所多，则互补互益（如一方火弱、另一方火旺）。双方五行严重同偏（如都金水极寒）则调候互难。

### 四、日主十神关系

看双方日主的生克关系 `[命理共识]`：双方日主相生相助（如甲木与乙木、甲木与丙火）为顺；相克（如甲木与庚金）为逆，需看双方命局能否化解。再参双方命局十神：一方官杀旺配另一方印旺（官印相生互补）、一方财旺配另一方比劫旺（能担财），均为互补良配。

## 第三部分：合盘应期法（共时应期）`[项目验证]`

> 关系事件（相见、定情、争执、成婚、分离）多为**两人盘同时被引动的共时产物**——单看一方盘的应期常错位。本部分为项目自创技法（核心骨架为古籍合冲体系 `[古诀]`，"共时应期"框架为本技法人所创 `[项目验证]`，引用时不冒充古诀）。

### 一、定义与原理

**同一流年 / 流月 / 流日地支，同时合动（合 / 冲 / 刑 / 害 / 伏吟）双方命局中"对应同一议题的宫位"→ 该议题事件在此时共时发生。** 双方引动 > 单方引动：共时应事的概率与烈度显著更高。

### 二、判定规则

1. **找双方对应议题宫位**：婚姻 / 亲密 → 双方**日支**（夫妻宫）；性事 / 隐私 → **时支**；同居 / 家宅 → 日支+时支（八字）或田宅宫（紫微）；六亲议题 → 对应六亲宫位。
2. **查当前流层（年 / 月 / 日）地支**对双方对应宫位的作用类型（合 / 冲 / 刑 / 破 / 害 / 伏吟）。
3. **作用类型定事件性质**：**合 = 成 / 聚 / 交好；冲 = 开 / 动 / 裂；刑 = 激烈搅动 / 磨合；伏吟 = 事发动 / 反复；害 = 暗损 / 小别扭**。
4. 共时（同一支动双方）＞ 单方：共时为"事件级"，单方为"心绪级"。

### 三、已验证案例（两例，脱敏）

| 案例 | 流层 | 引动 | 应事 |
|---|---|---|---|
| 1（年级） | 流年午 | **午戌合男方妻宫 + 午未合女方夫宫**——一支双合两人婚姻宫 | 当年婚恋之事成为两人共同主题，全年多次应事（会面、关系推进）✅ |
| 2（日级） | 流日卯（己卯日） | **卯戌合×2 男方（月 / 日支）+ 卯未合×2 女方（年 / 日支）**——一支双合两人婚姻宫；同时**卯冲女方时支酉（隐秘宫）** | 相见定情日；且"合夫宫 + 冲性宫"精确对应"关系推进而事有未竟"（合=成、冲=开而未成的行为级对应）✅ |

### 四、纪律（铁律）

1. **溯源标注**：合冲骨架 `[古诀]`，共时框架 `[项目验证]`，不混标；
2. **精度边界**：行为细节级断语（如亲密程度）属**取象延伸**——案例 2 仅一例验证，**只可作复盘解释，🔴 禁作事前预测**（"某日会发生 X 行为"类断语禁下）；
3. **用途限定**：用于已发生事件的复盘验证 + 月份级窗口提示（"某月成色高"级），不做日级行为预测；
4. **两体系独立**：八字体系用地支合冲 + 四柱宫位表述；紫微体系用流年走宫 + 四化落宫表述——各自使用不混术语。

## 第四部分：应事复盘六层法 `[项目验证]`

关系 / 合盘事件发生后，由粗到细逐层复盘验证：

| 层 | 查什么 | 要点 |
|---|---|---|
| 1 大运 | 双方当前大运主题交叠 | 一方收官期 × 一方开启期 = 事件窗口（如"财坏印收官 × 伤官情开"）|
| 2 流年 | 流年支对双方对应宫的**共时作用** | 年级基调（婚恋大年 / 考验年），见第三部分 |
| 3 流月 | 月支作用 + 透干十神 | 月内主题：刑动月=激烈搅动、合动月=易成、妻星 / 夫星透干月=感情事显 |
| 4 流日 | 日支对双方宫位的共时合冲 | 事件日精确对应，性质按合冲定性（合=成、冲=开）|
| 5 地点 | 地点五行 / 属性与双方星曜呼应 | 就星之地（赴财地会妻星 / 奔财星之城）；华盖人定情于艺术之地 |
| 6 行为模式 | 双方盘的"结构本能"在事件中的显影 | 印重=节制止礼、身弱就财=主动奔赴、合冲定事之成色 |

### 行为取象语言表（复盘断语词库）

| 取象 | 断语 |
|---|---|
| 合 | 成、聚、交好、事成交 |
| 冲 | 开、动、裂、激而未成 |
| 刑 | 激烈搅动、磨合、反复 |
| 伏吟 | 事发动、反复吟动、事件化 |
| 害 | 暗损、小别扭、心中不爽 |
| 印制 | 节制、止礼、理智把关 |
| 奔赴星地 | 就星而行（主动担财 / 就印等）|

### 合盘通用纪律

- 双方各自先独立推演，再对照合参；不可用一方盘套另一方结论。
- 缘分判断给"倾向性"结论，配概率与置信度，禁"命中注定必合/必分"等绝对化（SKILL 铁律第4条）。
- 应期类断语遵守第三部分纪律：复盘解释可以，日级行为预测禁下（铁律第2条"不编造"的应期版）。
